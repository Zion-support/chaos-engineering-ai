# Chaos Engineering AI

AI-driven chaos engineering that designs, runs, and learns from failure experiments to harden your systems before real outages strike.

## Features
- Automated experiment design from architecture maps
- Safe blast-radius controls & auto-abort
- Steady-state hypothesis verification
- Resilience scoring and regression tracking
